# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date: 12/10/2026

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

 Step 1: Preparation of Sheet & Reference Lines 
1. Fix the drawing sheet securely onto the drawing board using clips or 
drafting tape. 
2. Draw a suitable border line and create a title block at the bottom right 
corner. 
3. Based on the arrow marked "FRONT", establish the layout orientation: 
○ Front View (FV) will be drawn looking from the direction of the 
arrow. 
○ Top View (TV) will be projected directly below the Front View.

○ Side View (SV) (Right Side View) will be projected to the left or 
right of the Front View depending on First/Third Angle Projection 
conventions (typically First Angle is standard unless specified 
otherwise).

Step 2: Drawing the Front View (FV) 
1. Project or measure the overall base width of 100 mm horizontally and a 
total height of 50 mm vertically for the main body. 
2. Draw the main rectangular body outline. 
3. Locate the central cylindrical lens (ϕ50) on the front face: 
○ Center it horizontally across the 100 mm width. 
○ Draw the circular lens outline with a diameter of 50 mm. 
4. Add the top attachments visible from the front: 
○ Draw the profile of the central trapezoidal flash/viewfinder block 
showing the 45° slope feature. 
○ Draw the outlines of the smaller top buttons/dials on the upper 
surface. 
5. Darken the visible outlines using an HB pencil.

<img width="708" height="451" alt="{EC9EB26A-0C35-41A2-B89C-DBE41223ECD7}" src="https://github.com/user-attachments/assets/3dca09b6-4b08-4faf-a17b-0ef571295429" />

Step 3: Drawing the Top View (TV) 
1. Project vertical lines downwards from all major features of the Front 
View to align the width cleanly. 
2. Mark the total depth of the object, which is 35 mm for the main body 
plus the 20 mm lens projection (total depth extending to 55 mm). 
3. Draw the rectangular top profile of the camera body (100 mm width  ×
35 mm depth). 
4. Represent the cylindrical lens projecting forward by drawing its circular 
profile or projection boundaries corresponding to the depth of 20 mm. 
5. Draw the top square button block and the circular dial (ϕ20) positioned 
on the top surface layout using the given offset dimensions (e.g., 15 mm 
spacing references).

Step 4: Drawing the Side View (SV) 
1. Using a 45° miter line from the top-view projection boundaries or direct 
horizontal projections from the Front View, construct the Side View. 
2. Draw the overall depth box (width/depth of 35 mm) and height (50 mm 
base plus top components). 
3. Outline the profile of the camera body from the side, indicating how the 
lens protrudes forward by 20 mm and how the top attachments sit on the upper tier.

Step 5: Dimensioning and Final Finishing 
1. Dimension all crucial features clearly using thin lines, extension lines, 
and arrowheads (e.g., overall length 100, height 50, depth 35, lens 
diameter ϕ50, lens projection 20, dial diameter ϕ20). 
2. Ensure all hidden details (if any internal cavities exist) are represented 
using dashed/dotted lines, though most visible features here are 
external. 
3. Clean up any extra construction lines, check dimension accuracy  
4. against the reference drawing, and darken the final object lines.
